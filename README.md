This repository contains a class project on predicting whether a mushroom is edible (e) or poisonous (p) based on observable physical characteristics. The project demonstrates how machine learning techniques can be applied to a real-world, safety-relevant classification problem by following a complete and structured workflow, from data exploration to model evaluation.

The work begins with exploratory data analysis (EDA) to understand class distribution, feature behavior, and the presence of missing values. Careful preprocessing is applied, including handling missing categorical data, one-hot encoding of categorical features, feature scaling, and stratified train–test splitting. Several supervised learning models are then trained and evaluated, including K-Nearest Neighbors (KNN), Decision Tree, and a Neural Network (MLP). Model performance is assessed using multiple evaluation metrics such as accuracy, precision, recall, F1-score, confusion matrix, and ROC–AUC to ensure reliable comparison beyond accuracy alone. In addition, an unsupervised learning perspective is explored using K-Means clustering with PCA visualization to examine the underlying structure of the data.

This project was developed primarily as a learning exercise and is intentionally kept clear and modular. It can be extended in many ways, such as experimenting with additional models, performing deeper hyperparameter tuning, applying feature selection techniques, or combining multiple approaches into a hybrid system.
